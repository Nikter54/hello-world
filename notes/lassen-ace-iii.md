# Trimble ACE III / Lassen — нотатки щодо конфігурації

Статус: початкові дані, модель і плату ще не підтверджено.

## Що встановлено
- Окремого продукту «Lassen ACE-III» у знайдених джерелах немає. У Trimble це дві окремі лінійки:
  - **ACE III GPS** — GPS-модуль (core module) для вбудовування.
  - **Lassen** (SK8, LP, SQ, iQ) — інша лінійка модулів Trimble.
- Даташит ACE III: Trimble TID11736C (8/02), копія: https://docs.ampnuts.ru/eevblog.docs/Trimble/Data%20Sheets/AceIII.pdf
  (офіційна сторінка, вказана в даташиті, http://www.trimble.com/aceiii.html, — модуль давно знято з виробництва; її наявність не перевіряв).

## ACE III за даташитом
- L1 C/A, 8 каналів, оновлення 1 Гц; 1PPS ±95 нс.
- Живлення +5 В ±5 %, ~95 мА; резервне живлення +3,2…+5 В.
- Роз'єми: антена SMB; I/O — 8-пін (2x4) 2 мм. Два послідовні порти, рівні CMOS TTL (не RS-232!).
- Протоколи за замовчуванням: TSIP 9600 8-O-1; NMEA 0183 v2.1 4800 8-N-1; RTCM SC-104 4800 8-N-1; також TAIP.
- NMEA: GGA, VTG, GLL, ZDA, GSV, GSA, RMC — вибір командою TSIP, зберігається в енергонезалежній пам'яті.
- Налаштування задаються командами TSIP і можуть зберігатися в енергонезалежній пам'яті.

## Невідомо (потрібен посібник — Reference Manual зі Starter Kit)
- Перелік і коди пакетів TSIP для налаштувань (маски висоти/PDOP, динаміка, порти тощо).
- Розпіновка 8-пінового роз'єму.

## Програма конфігурування: Trimble GPS Studio
Джерело: Trimble GPS Studio Application User Guide, Version 1.01.20, Revision B, August 2011 (файл від Миколи).
У Миколи встановлено версію **1.84.0** — опису саме цієї версії немає; відмінності від 1.01.20 невідомі.

- Підключення: New Connection → COM-порт → «Auto-detect settings» (сама підбирає протокол, швидкість, парність, біти).
- Налаштування: Receiver → Configure. Вкладки (набір залежить від приладу):
  - Port Configuration — порт, швидкість, парність, біти даних/стоп, один вхідний і один вихідний протокол;
  - Outputs — параметри виводу;
  - PPS Configuration — Always ON / Fix-based / Always OFF, зсув і ширина імпульсу (нс), полярність;
  - NMEA — речення (GGA, GSV, RMC, GLL, GSA, VTG, ZDA, TF1, BA1, GST, CHN1 — не всі є на всіх приладах), інтервал 1–255 с.
- На кожній вкладці — Set; наприкінці один раз Save Configuration (запис у енергонезалежну пам'ять).
  У модулів Condor ліміт 8 збережень, далі — перепрошивка (для ACE III про такий ліміт у посібнику нічого не сказано).
- Інші інструменти: Data Logger, Data Converter, Generic Packets (надсилання сирих пакетів, напр. TSIP), Flash Loader.
- ACE III і Lassen у посібнику **не згадані** (приклади — Condor, Copernicus II). Чи підтримує GPS Studio ACE III — невідомо; перевірити на практиці (Auto-detect + Configure).

## Плата Миколи (за фото, 2026-11-19)
- Наклейка «39818-00-C REV.C5», плата «PII-III 39818-C», ПЗП «43018-02 V8.08» (ймовірно, версія прошивки 8.08), дата 0228.
- Номер 39818-00-C в документації ntpsec вказано як ACE III: https://docs.ntpsec.org/latest/driver_trimble.html — отже, це **Trimble ACE III**.
- На платі є перехідник «GPS Cable Adapter 1.0, PacComm, Tampa FL» — прилад, найімовірніше, вбудований у виріб PacComm.

## Завдання: Порт B → вивід NMEA ZDA
План у GPS Studio (не перевірено на ACE III):
1. Підключитися до порту, що працює в TSIP (за замовчуванням TSIP 9600 8-O-1), Auto-detect.
2. Receiver → Configure → Port Configuration: Receiver Port = B, Output protocol = NMEA, швидкість (типово 4800 8-N-1 — або яка потрібна приймальній стороні) → Set.
3. Вкладка NMEA: лише ZDA, інтервал 1 с → Set.
4. Save Configuration. Перевірити, підключившись до порту B.
Запасний шлях — TSIP через Generic Packets: у загальних таблицях TSIP порт задає пакет 0xBC, NMEA — 0x7A; точний формат байтів для ACE III не підтверджено (потрібен Reference Manual).

## Конфігурація в GPS Studio 1.84.0 (скріншоти Миколи, Configurator, «Other Embedded»)
- Port A: 9600, None, 8, 1; вхід/вихід TSIP. (За даташитом заводське TSIP — 8-**Odd**-1; після запису підключатися з 9600 8-N-1.)
- Port B: 4800, None, 8, 1; вихід NMEA, вхід не вибрано.
- GPS: Auto 2D/3D, Land, DGPS Auto On, WGS-84, Elevation mask ~5°, Signal mask 3, PDOP mask 12, switch 5.
- Timing Receiver Settings — усе вимкнено (для ACE III так і треба: це пакети 0x8E для таймінгових приймачів).
- Вибір речення ZDA на цих вкладках не видно — ймовірно, на «Miscellaneous Settings» (скріншота ще немає).
- Miscellaneous Settings (було): NMEA Output увімкнено, інтервал 5 с, вибрано лише **GGA**, ZDA — ні. Треба: ZDA ✔, GGA ✘ (якщо потрібен лише ZDA), інтервал 1 с → Configure Receiver(s).
- Перевірка порту B (вивід Миколи): `$GPGGA,042936.0,,,,,0,00,...` щосекунди — інтервал 1 с застосувався, але йде GGA, а не ZDA; фіксу немає (якість 0, супутників 00).
- Ризик (не перевірено): прошивка 2002 р. — можлива проблема переповнення GPS-тижня (1024 тижні); після фіксу звірити дату в ZDA з реальною.
- Вичитана з приладу конфігурація (Miscellaneous Settings): NMEA Output ✔, інтервал 1 с, вибрано лише **ZDA** — у приладі записано правильно. Далі: перевірити фактичний вивід порту B, у т.ч. після вимкнення/увімкнення живлення.
- Після вичитаної конфігурації «лише ZDA» порт B досі видає GGA (04:34:39…), фіксу немає. Причина невідома. Версії: (а) прошивка 8.08 трактує маску NMEA (0x7A) інакше, ніж GPS Studio; (б) ZDA не видається без валідного UTC (немає супутників), а GGA — запасний; (в) конфігурацію не записано/не застосовано. Наступний крок — отримати фікс (антена), потім повторити перевірку.
- Перезапуск живлення не допоміг — порт B і далі видає GGA. Діагностика: вибрати лише RMC (або GGA+ZDA) і подивитися, чи змінюється вивід.
- Антени зараз немає (буде активна) — тому 0 супутників. Вимога за даташитом: живлення антени 5 В, до 25 мА.
- Вибір RMC теж не змінює вивід — порт B завжди видає GGA. Отже, вибір NMEA-речень з GPS Studio прилад не застосовує.
- Знайдений TSIP Reference (Trimble 34462-00 Rev C, 04/1999) стосується DSM/Placer, не ACE III — для ACE III не використовувати.
- Гіпотеза: пристрій PacComm, у який вбудовано модуль, при старті сам переналаштовує GPS (напр. на GGA). Перевірити, чи порт приладу PacComm живить/керує модулем під час тесту.
